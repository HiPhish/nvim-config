This is a short reference for the American Standard Code for Information
Interchange (ASCII) character code. The values have been taken from the
Wikipedia article on ASCII:

    https://en.wikipedia.org/wiki/ASCII

==============================================================================
ASCII LIST                                                        *ascii-list*
------------------------------------------------------------------------------

The first four colums are the character code in binary, octal, decimal and
hexadecimal representation respectively. The next four columns are the
abbreviation, Unicode representation, caret-notation, and escape sequence
using in C and many other programming languages (the sequence for the `ESC`
character is non-standard).

If there are multiple possible values, only the most recent one (from 1967) is
included in order to save space.
